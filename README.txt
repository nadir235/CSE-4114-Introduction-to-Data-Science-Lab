20 standalone Data Science projects. Run any file:  python 01_titanic_survival_classification.py
Needs: pip install pandas numpy matplotlib seaborn scikit-learn openpyxl
Each script downloads its dataset from a URL, runs the full workflow and saves figures/tables/run_log.txt in ./outputs/<project>/
Project 20 (Obesity): if the UCI download is blocked, download the CSV manually and run:  DATA_PATH=/path/to/ObesityDataSet_raw_and_data_sinthetic.csv python 20_obesity_levels_classification.py
(in Google Colab it will open an upload dialog instead)
